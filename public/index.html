OpenVoice Developer API

          
Use these endpoints from any publik app or external script.

          
curl -X POST http://localhost:3001/api/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"Hello from publik!","voiceId":"af_heart","format":"wav"}' \
  --output speech.wav

          
GET  /api/voices           # List Kokoro, Chatterbox & cloned voices
POST /api/tts              # Synthesize & watermark speech
POST /api/voices/design    # LLM voice design -> 3 variations
POST /api/voices/clone     # Clone voice (sampleAudio + consentAudio of the consent phrase)
POST /api/llm/direct       # Add pauses & emotion tags
POST /api/llm/write        # Topic -> script
POST /api/llm/translate    # Translate script
POST /api/agent/turn       # STT -> LLM -> TTS turn
POST /api/watermark/verify # Verify invisible OpenVoice WAV watermark
